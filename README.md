## 🛠️ Tecnologías Aplicadas
- **HTML5 Semántico:** Uso de etiquetas estructurales (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), jerarquía de encabezados y atributos ARIA de accesibilidad.
- **CSS3 Moderno:**
  - Variables CSS personalizadas (CSS Custom Properties) para soporte de **Modo Oscuro / Modo Claro**.
  - Layouts fluidos y adaptativos construidos exclusivamente con **CSS Grid** y **Flexbox**.
  - Media queries optimizadas para dispositivos móviles (≤ 480px), tablets (≤ 768px) y escritorios.
  - Paleta de color con contraste verificado bajo estándares WCAG AA/AAA.
- **JavaScript ES6+ (Vanilla):**
  - Menú hamburguesa accesible y reactivo en dispositivos móviles.
  - Alternador de tema (Dark/Light Mode) con persistencia en `localStorage`.
  - Detección de sección activa en la barra de navegación mediante la API `IntersectionObserver`.
  - Filtro dinámico de proyectos por categoría tecnológica.
  - Validación en tiempo real del formulario de contacto.
  - Botón interactivo de retorno al inicio ("Back to Top").

## 🌿 Flujo de Trabajo Git Flow y Conventional Commits
El desarrollo de este portafolio siguió estrictamente la convención de ramas y commits solicitada en la rúbrica:

### Estructura de Ramas
- `main`: Rama de producción lista para despliegue en GitHub Pages.
- `develop`: Rama principal de integración y desarrollo.
- `feature/estructura-html`: Maquetación y marcado semántico.
- `feature/estilos-css`: Estilos responsive, paleta de colores y variables.
- `feature/interactividad-js`: Lógica del menú móvil, filtros y temas.
- `feature/documentacion`: Documentación README y metadatos.

## 🌿 Metodología y Buenas Prácticas
El proyecto fue construido siguiendo estándares de la industria:
- **Git Flow:** Ramas estructuradas para producción (`main`), integración (`develop`) y características específicas (`feature/*`).
- **Conventional Commits:** Mensajes de confirmación semánticos y estandarizados (`feat:`, `style:`, `docs:`, `chore:`).
- **Semántica & Accesibilidad:** Marcado estándar HTML5 validado y contrastes certificados para accesibilidad.
